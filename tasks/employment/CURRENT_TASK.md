# 就业情报 Campaign 任务（2026 届 / 2027 届，1000 篇）

> 状态：已授权执行（V4，2026-11-09）。
> 本文件是任务定义，不记录执行进度；进度写入 `runs/<run-id>/progress.md` 与 Campaign/Batch 检查点。

## 任务名称

就业情报 1000 篇文章与评论区采集（2026 届 / 2027 届）

## 目标

在合法可访问的范围内，通过 Playwright MCP 操作真实 Chrome，采集并结构化 1000 篇与 2026 届 / 2027 届秋招、校招、补录和应届就业相关的文章（含知乎、小红书），并为每篇采集评论区：

- 一级评论：每篇最多 50 条；
- 楼中楼：选中一级评论下尽可能采集全部可访问回复，不计入 50 条；
- 评论作者身份信息不入库。

文章数不包含评论和楼中楼回复。

## 配额

| 维度 | 目标 |
|---|---:|
| 唯一文章合计 | 1000 |
| 小红书 | 800 |
| 知乎 | 200 |
| 2026 届 | 400（初始目标） |
| 2027 届 | 600（初始目标） |

配额可根据真实结果调整，但不得重复登记、伪造来源或错误标记届别。上一轮 12 条历史记录需先审计：符合条件可复用并计入 1000；缺少评论的补采；不符合条件的保留历史记录但不计入 Campaign。

其他站点必须先经用户同意并写入本文件后才能访问。

## 评论规则

严格按 `docs/ARCHITECTURE_EMPLOYMENT.md` 第 5 节：

1. 一级评论 ≤50：全部采集可访问部分；
2. 一级评论 >50：高赞前 30 + 最新前 20，去重补足；
3. 无排序/点赞不可见时按可见顺序并记录限制；
4. 每条选中一级评论下尽可能展开全部楼中楼与子回复；
5. 分别记录页面显示数、实际采集数、排序方式、覆盖状态与未采集原因；
6. 中断保存 checkpoint，标记 `partial`。

## 执行方式

1. 读取 `AGENTS.md`、`docs/WORKFLOW.md`、`docs/ARCHITECTURE_EMPLOYMENT.md`、平台手册、本文件。
2. 创建 Campaign / Run / Batch；写入 SQLite。
3. Playwright MCP 操作真实 Chrome：搜索、点击、滚动、详情读取、评论展开、排序切换。
4. 登录、验证码、设备确认由用户在可见 Chrome 中完成；Agent 不接触密码或 Cookie。
5. 页面数据整理为标准结构，经 Python 校验、去重后入库。
6. 生成文章/评论 Markdown、索引、批次进度与 checkpoint。
7. 每批核对 SQLite、Markdown 与计数，更新报告。

## 禁止事项

- 不绕过验证码、访问控制、登录限制或风控；不使用代理池、指纹伪装、隐藏/逆向接口。
- 不采集评论作者昵称、头像、用户 ID、主页、简介、地理位置或联系方式。
- 不进行点赞、收藏、评论、关注、私信、发帖、投递等互动。
- 不伪造时间、点赞数、评论总数、排序方式或核验状态。
- 不把采集数据、SQLite、Markdown 档案、Profile、Cookie、Token 提交 Git。
- 不删除历史数据或强制推送。

## 输出要求

- SQLite：文章、评论、Campaign、Batch、Artifact 及关联关系。
- `data/employment/<platform>/{posts,comments,indexes}/` Markdown 档案。
- `data/employment/reports/` 报告。
- `runs/<run-id>/`：任务快照、进度、结果、checkpoint。
- 脱敏阶段摘要写入 `docs/acceptance/EMPLOYMENT_V4_PHASES.md`。

## 停止条件

- 用户要求停止；
- 出现无法由用户当场完成的登录/验证；
- 403、持续限流、验证码循环、账号安全提示或权限拒绝；
- 平台页面结构发生重大变化，现有手册无法安全继续；
- 达到配额或本轮时间预算。

## 验收标准

- 文章、一级评论、楼中楼分别统计，报告与 SQLite 一致；
- 每篇文章有 Markdown 档案；每篇有评论档案（无评论也要说明）；
- 评论父子关系合法，无作者身份字段；
- 页面显示数与实际采集数分开记录；
- `PRAGMA integrity_check=ok`，外键检查无异常；
- 测试全部通过；
- Git 不包含采集数据、SQLite、Profile、Cookie 或 Token；
- 未完成数量如实报告，`partial` 不改写为 `completed`。
