# 知乎采集手册

本手册记录通过 Playwright MCP 操作知乎真实页面时的可复用步骤。页面结构会变化，选择器需在每次任务中先验证。

## 1. 搜索

- URL 模板：`https://www.zhihu.com/search?type=content&q=<URL 编码关键词>`
- 结果项：问题、回答、专栏文章。优先打开问题页与专栏页，回答页可作为补充。
- 记录：页面显示结果数、实际打开数、新增唯一文章数、重复数、排除原因。
- 登录：未登录时可能出现登录弹窗；暂停，请用户在可见 Chrome 中完成。

## 2. 详情读取

- 问题页包含标题、问题描述、回答列表；专栏页包含标题、作者、正文。
- 只读取任务必需字段：标题、规范 URL、发布时间、招聘阶段、企业/城市（明确出现时）、有限事实与自写摘要。
- 发布时间：页面显示“发布于/编辑于 YYYY-MM-DD HH:MM”时可记录为 ISO-8601；只有相对时间时保留原文，不推算。
- 不复制长正文，不保存作者昵称、主页、头像或联系方式。

## 3. 评论

1. 页面底部或回答下方可能显示“N 条评论”；点击进入评论区。
2. 读取页面显示的评论总数；能区分一级评论时记录一级总数。
3. 一级评论 ≤50：采集全部可访问评论；>50：高赞前 30 + 最新前 20，去重补足。
4. 排序：页面提供“按热度/按时间”等选项时切换并记录；无选项时按可见顺序。
5. 楼中楼：点击“展开回复”“查看更多回复”等入口，尽可能展开全部可访问回复；多层回复保留父子层级。
6. 计数：分别记录页面显示数、实际采集一级数、页面显示回复数、实际楼中楼数、覆盖状态、排序策略。
7. 中断：保存 checkpoint，线程标记 `partial`；恢复时先查 SQLite，不重复采集。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 登录弹窗 | 暂停，请用户手动登录；不索取密码 |
| “展开全文” | 可点击，仅读取展开后的可见内容 |
| 评论区需登录 | 暂停；用户确认后继续；仍不可用则标 `blocked` |
| 验证码/设备确认 | 暂停交回用户；不绕过 |
| 403/限流 | 停止该批，记录时间与现象，继续另一平台 |
| 页面结构变化 | 停止该批，更新本手册后再继续 |

## 5. 禁止

- 不调用隐藏/逆向接口，不抓取登录态 API。
- 不保存评论作者身份字段与联系方式。
- 不进行点赞、收藏、评论、私信、发帖等互动。
- 不伪造点赞数、评论总数、排序方式或发布时间。
