## 2. 调度器升级（`keyword_planner.py`）

四层策略：

1. **主题多样性**：按 `目标 − 已采集 − 队列中` 的缺口比例选维度；
2. **探索 / 利用**：维度内未搜索过的关键词优先（探索），已搜索的按
   `accepted / searches` 排序，并优先最久未搜索的（利用）；
3. **年份多样性**：修饰词轮换，一次一个；
4. **动态关键词**：需人工批准后才进入调度。

调度指标已落库：搜索次数、发现候选数、新候选数、详情打开数、相关性合格数、
采纳数、最近搜索时间（`engine_query_runs` 聚合）。

### 与 V6.1 基线的对照（口径相同）

| 指标 | V6.1（54 次搜索） | V6.2（5 次搜索） |
